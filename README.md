Kingdom Foxes' Wynncraft mod that embeds Raid LFGs In-game. Alongside many chat tweaks, Guild war improvements, Fixes to Wynntils features and much more.  
(includes an occasional piano)

## Features

* About
   * Edit HUDs
   * Interface Font (Vanilla or Karla)
   * UI Themes (community palettes)
* Chat
   * Edit Chat Layout
   * Appearance
      * Hide Chat Scrollbar
      * Remove Chat System Indicators
      * Chat Timestamps
   * Input
      * OW-like Chat Tabbing
   * Guild Ranks
      * Internal Guild Ranks (Fox Exclusive)
      * Guild Rank Style
   * Message Direction
   * Custom Horizontal Alignment
   * Custom Text Shadow
   * Chat History
      * Persistent Chat
      * History Limit
   * Screenshots
      * Chat Screenshotting
      * Snap to Text
      * Smooth Selection
      * Chat Selection Sounds
      * Instrument
* Raid LFG (Fox Exclusive)
   * Enable Raid LFG
   * Edit Notification Position
   * Notifications
      * New Party Notifications
      * Reopened Party Notifications
      * Party Status Notifications
      * Auto Pop-out
      * Raid LFG Sounds
   * Controls
      * Open, Join, Close Notification, Leave / Disband, Party Filled, Ping, and Lock / Unlock (F1-F7 by default)
      * Automatic Raid Requeue (unbound by default)
* Wheels
   * Party Create
      * Party Create toggle
      * Wheel Style (Circle Segments, Bars, or No View)
      * Create Modifier Keybind (F8 by default)
   * Party Kick
      * Party Kick toggle
      * Wheel Style (Circle Segments, Bars, or No View)
      * Kick Modifier Keybind (F9 by default)
   * Class Switcher
      * Class Switcher toggle
      * Wheel Style (Circle Segments, Bars, or No View)
      * Class Modifier (unbound by default)
      * Class Shortcuts (detected characters, local names, order, and option keys)
* War
   * Point and Laugh (custom guild-chat message when nobody logs in for a war)
   * Attack Timers
      * Show Who Queued
      * KoF Rank Colors (Fox Exclusive)
      * Your Queue Color
   * Territory Map
      * HQ Distance and Queue Estimate
      * Inspection Keybind (either Ctrl key by default)
   * Consumable Highlights
      * Highlight Rules (displayed item names and aliases)
* Supporter
   * Material Resolution
   * Nameplate Color
   * Show Own Nametag

Open `/ralle settings` to configure these options, `/ralle hud` to edit HUD placement, or `/ralle lfg` for Raid LFG.

Class Switcher is disabled by default and works independently of Fox membership or Raid LFG access. Enable Auto Open in Wynncraft's character menu and open `/class` so RALLE can observe it before enabling the switcher. Characters are discovered from game data you receive naturally; shortcuts and name overrides stay local to your Minecraft account. Removing a shortcut never deletes a character. Press Escape to cancel a switch.

Fox-exclusive settings require confirmed current Kingdom of Foxes membership. Supporter settings require a current Fox cosmetic grant (Supporter, Contributor, or Admin). The War tools that extend the territory map or attack timers require compatible Wynntils.

Fresh installs enable chat screenshots, Snap to Text, selection sounds, persistent chat with a 300-message session history, and Raid LFG with its notification, sound, and pop-out options. Raid LFG stays inactive until Fox membership is confirmed. Other optional features start disabled.
